# Phase 5 — UI (done)

Tab order: **Cover**, **Voice conversion**, **Separation** (5 architecture sub-tabs), **Voices**,
Themes, Settings, Credits.

- `ui/rvc_controls.py`: shared voice dropdown, `refresh_voices`, the `rvc_settings()` widgets keyed by
  `RvcParams` field names, and `rvc_params(values)`.
- `ui/tabs/cover.py`, the full pipeline:
  - Inputs: voice, song (upload or yt-dlp link), preset dropdown (fills the five stage dropdowns;
    "Skip this step" = `""`).
  - Accordions: RVC settings, backing vocals (voice + pitch), vocal effects, and mix (key shift,
    gains, format, keep stems).
  - Batch folder mode with a Stop button.
  - API endpoints: `make_cover`, `make_covers_batch`, `download_song`.
- `ui/tabs/convert.py`: RVC only, single file and batch. API: `convert_voice`,
  `convert_voice_batch`.
- `ui/tabs/voices.py`: installed voices table, download by link, upload `.pth`/`.index`/`.zip`, and
  delete. After each change it refreshes the voice dropdowns in Cover and Voice conversion. API:
  `download_voice`, `upload_voice`, `delete_voice`.
- Settings: new "Cover cache" accordion showing the workspace size and a Clear button.
- The planned **Mixer tab was dropped**. With the stage cache, re-running Cover with new mix, effect
  or key settings only re-mixes, so it does the same job.

Conventions kept from UVR5-UI:
- Handlers take `inputs_kwargs`; the parameter names are the API names. Components that would be
  shadowed are aliased (e.g. `audio_input`).
- Validators run before queueing.
- Every GPU job uses `concurrency_id=GPU_CONCURRENCY_ID`.
- Each tab has an `a11y.tab_heading`.

i18n: 252 keys, complete in es_ES and pt_BR. Preset descriptions come from
`assets/pipeline_presets.json` and stay in English for now.

## Verification

- `tests/test_ui.py` (26 tests):
  - tab order, and the accessibility checks (labels, distinct buttons, headings) on the new tabs;
  - Cover option building (ints, `""` meaning skip, backing pitch, effects) and validators;
  - presets; voice conversion; voices upload and delete.
- Full suite: 126 passed.
- Live app: `python app.py --listen-port 7757`, then a `gradio_client` call to `/make_cover` with the
  test song and the Atri voice. It produced
  `outputs/test_edited (Atri atri_e375_s6000 Cover).flac`, and the second call reused the cache.

Known leftover: `/lambda_*` API entries come from Settings dropdown initializers inherited from
UVR5-UI (`value=lambda: None`). They are harmless; hiding them would mean changing those components.
